## Add it to a page

<div class="try-it">
  <button class="toon-press try-button" type="button">Press me</button>
  <p>Hold it down. <code>.toon-press</code> squashes the button while you hold it and lets it overshoot a little when you let go.</p>
</div>

Copy [`toon.css`](toon/src/toon.css) and [`toon.js`](toon/src/toon.js) into your project and include them. There's no package to install and no build step. toon isn't published to npm.

```html
<link rel="stylesheet" href="toon.css">
<script src="toon.js"></script>
<button class="toon-press">Press me</button>
```
