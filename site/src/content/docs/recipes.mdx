## A character jump, scripted

This uses **anticipation**, **squash and stretch**, **slow in and slow out** and **timing**. Each `tween` is one beat, and `sequence` plays them in order. A `withSquash` pivot at the ball's base keeps it planted while it squashes:

<Recipe file="character-jump.html" />

## Throwing something along a path

**Arcs** plus **squash along velocity**. Running a quadratic arc with linear timing gives true projectile motion:

## Respect reduced motion on canvas

`toon.css` handles reduced motion for you. On canvas, check the media query yourself and either jump to the end state or slow decorative motion right down:

<Recipe file="reduced-motion.html" />

When the clock is frozen, tweens stop advancing, so set any element that must reach its final state directly (for example, `onComplete` values) instead of animating to it.
