Almost nothing in nature moves in a straight line. A thrown ball traces a parabola, a turning head sweeps an arc, and a waving hand follows a curve. Straight-line motion reads as robotic.

## Arcs in CSS

```html
<div class="toon-arc toon-loop toon-yoyo" style="--toon-distance:240px; --toon-height:140px">
  <div class="ball"></div>
</div>
```

The wrapper and its child each animate one axis with a **different easing**: the wrapper's `translate` moves along x linearly, and the child's `translate` rises and falls on gravity easing. Together they trace a real parabola. Because both animate only `translate`, the browser runs them on the GPU, with no main-thread work per frame. The child inherits the wrapper's `.toon-loop` / `.toon-yoyo`.

## Arcs in Canvas

```js
const fly = Toon.arc(from, to, { height: 120 });   // apex ~120px above the chord
Toon.tween({ duration: 900, ease: Toon.ease.linear, onUpdate: t => (pos = fly(t)) });
```

Give `arc()` **linear** timing and you get a real throw: the object moves sideways at a steady speed while its height rises and falls like a thrown ball. To pass through several points, use `path()`, which draws a smooth curve through them (a [Catmull-Rom curve](../../glossary/#catmull-rom-curve)), and use `tangent()` to face the direction of travel:

```js
const route = Toon.path([{ x: 40, y: 200 }, { x: 160, y: 60 }, { x: 300, y: 160 }, { x: 420, y: 40 }]);
const p = route(t), angle = Toon.tangent(route, t);
```

> **Runnable code.** This snippet leaves out the setup (canvas, stage and drawing). For the complete code, open **Show the demo's source** under the demo above, or see the [throwing recipe](../../recipes/#throwing-something-along-a-path), which runs as-is.

## Arcs: tuning tips

- **Check your arcs with ghosts.** Plot past positions, as the demos do. Kinks and flat spots show up immediately.
- **Combine with squash.** Stretch along the tangent while the object moves fast (see [Squash & stretch](../squash-and-stretch/)).
- **UI paths can arc too.** A slight curve on a card flying to a cart, or a dialog swooping in, feels more natural than a straight slide.

**API:** [`arc` / `path` / `tangent`](../../api/canvas/#motion-paths), [`.toon-arc`](../../api/css/#classes)
